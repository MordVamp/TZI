# 🟢 ГАЙД ДЛЯ ЧАЙНИКА — Лаб 2: Защита ПО от изменения и копирования (DRM)

---

## ШАГ 0 — Запуск программы

```bash
# Из корня workspace (папка TZI/)
cargo run -p lab2

# ИЛИ если ты уже в папке lab2/
cargo run
```

Откроется окно с 4 вкладками: **Шифрование | Просмотрщик | Лицензии | Отпечаток**

---

## ШАГ 1 — Подготовить тестовый файл

Создай простой текстовый файл для демонстрации:

```bash
echo "Это секретный документ. Только для авторизованных пользователей!" > /tmp/secret.txt
```

---

## ШАГ 2 — Зашифровать файл

1. Нажми вкладку **🔒 Шифрование**
2. В поле "Путь к файлу" введи: `/tmp/secret.txt`
3. В поле "Пароль шифрования" введи: `mysecretpass123`
4. Нажми **Зашифровать**

**Результат:**
- Появится файл `/tmp/secret.txt.drm` — зашифрованный (base64)
- Показан лицензионный ключ формата `ABCD-1234-EFGH-5678`
- В папке `target/debug/licenses/` появится файл `secret.txt.drm.license`

Проверь что файл зашифрован:
```bash
cat /tmp/secret.txt.drm
# Выведет нечитаемую base64-строку
```

---

## ШАГ 3 — Открыть зашифрованный файл (по паролю)

1. Нажми вкладку **🔓 Просмотрщик**
2. Путь к файлу: `/tmp/secret.txt.drm`
3. Метод доступа: **По паролю**
4. Пароль: `mysecretpass123`
5. Нажми **Открыть файл**

✅ Должно появиться содержимое: "Это секретный документ..."

Теперь попробуй неверный пароль:
- Пароль: `wrongpassword`
- ❌ "Неверный пароль или файл повреждён"

---

## ШАГ 4 — Открыть по лицензионному ключу

1. Вкладка **🗝 Лицензии**
2. Введи имя файла: `secret.txt.drm`
3. Нажми **Сгенерировать ключ**
4. Скопируй ключ (кнопка 📋)

Теперь:
1. Вкладка **🔓 Просмотрщик**
2. Путь: `/tmp/secret.txt.drm`
3. Метод доступа: **По лицензии**
4. Вставь скопированный ключ
5. Нажми **Открыть файл**

✅ Файл откроется без ввода пароля.

---

## ШАГ 5 — Показать что ключ привязан к компьютеру

Объяснение для преподавателя:

> «Лицензионный ключ вычисляется как SHA-256 от мастер-секрета, аппаратного отпечатка (username + hostname + RAM) и имени файла. На другом компьютере аппаратный отпечаток будет другим → ключ не совпадёт → файл не откроется.»

Показать в программе:
1. Вкладка **💻 Отпечаток**
2. Показать параметры системы и SHA-256 хеш

---

## ШАГ 6 — Проверить файл лицензии

```bash
cat target/debug/licenses/secret.txt.drm.license
```

Выведет:
```json
{
  "key": "ABCD-1234-EFGH-5678",
  "fingerprint": "<sha256 хеш>",
  "filename": "secret.txt.drm"
}
```

## ШАГ 7 — Зашифровать разные типы файлов

```bash
# PDF (если есть)
echo "PDF content demo" > /tmp/doc.pdf
# Бинарный файл тоже работает (но просмотрщик покажет бинарщину)

```

В программе зашифровать оба файла → показать что у каждого свой ключ.

## 🚀 Быстрый сценарий для защиты (5 минут)

```bash
# 1. Создать тестовый файл
echo "Секретные данные компании ООО Ромашка" > /tmp/test.txt

# 2. Запустить программу
cargo run -p lab2
```

В программе:
```
1. Шифрование → path=/tmp/test.txt, пароль=Test123! → Зашифровать
2. Запомнить лицензионный ключ из статуса
3. Просмотрщик → path=/tmp/test.txt.drm → По паролю → Test123! → Открыть
4. Просмотрщик → неверный пароль → ошибка ❌
5. Лицензии → test.txt.drm → Сгенерировать → скопировать
6. Просмотрщик → По лицензии → вставить ключ → Открыть ✅
7. Отпечаток → показать параметры
```

## ⚠️ Частые проблемы

| Проблема | Решение |
|---------|---------|
| "Файл не найден" | Убедись что путь абсолютный: `/tmp/test.txt` |
| "Ошибка base64" | Файл не является DRM-файлом (не зашифровывался этой программой) |
| "Ключ недействителен" | Ключ сгенерирован на другом пользователе/машине или неверно введён |
| Программа не запускается | `cargo build -p lab2` — посмотреть ошибки |
